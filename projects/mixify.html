Mixify

Built a React app that recommends tracks by tempo and musical key, then exports mixes to Spotify playlists.

React · ReccoBeats API · Spotify Web API · Jest

Application & recommendation logic · March 2026

GitHub ↗

Overview

A song can fit someone’s taste and still be difficult to mix into a set. Mixify focuses on the transition between tracks: tempo, harmonic compatibility, and enough variety to keep the mix interesting.

My contribution

I built a React app for finding tracks, assembling a mix, and exporting it to a private Spotify playlist. ReccoBeats supplies audio features, while the Spotify Web API supports catalog and playlist workflows. The recommendation logic puts mixing constraints directly into the selection process.

Recommendation choices

The base tempo window is ±5 BPM. Half-time and double-time comparisons account for transitions that share a pulse at different apparent tempos. Camelot-wheel relationships provide a practical harmonic-compatibility rule. Filtering out the seed artist encourages variety rather than simply returning more of the same artist.

Recommendation approach

Tempo and key provide interpretable domain constraints and work without collecting a large listening-history dataset. A user can understand why a track was suggested. That makes the approach useful for a focused mixing tool, while leaving room for a later preference model.

Evidence & limits

The repository documents search, mix assembly, recommendations, and Spotify export. Tempo/key compatibility is a useful filter, not a guarantee of a good transition: phrasing, energy, arrangement, and the DJ’s intent still matter. API access and Spotify authorization are required for the original application; this case study does not depend on them.

What I would evaluate next

Ask DJs to compare the usefulness and diversity of suggestions, measure which recommendations they keep, and separate technical compatibility from subjective fit. Any ranking improvement should be tested against the simple, explainable baseline.
