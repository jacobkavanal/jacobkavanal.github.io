Greening Earth

Processed NASA MODIS vegetation data into a browser-based map with 592,800 cells per layer. Built a binary grid format to reduce transfer size.

Python · NumPy · rasterio · GeoJSON · Three.js

Geospatial processing & visualization · August 2026

GitHub ↗

Overview

Satellite rasters contain rich environmental information, but multi-gigabyte source files are not a useful starting point for someone exploring a map in a browser. This project connects the data-processing work to a visual question: how does vegetation differ across places and years?

My contribution

I built a Python pipeline using NumPy and rasterio to transform MODIS vegetation rasters into normalized cells. I also worked on the browser rendering and a custom binary grid format, so the visualization could use dense data without repeatedly transferring large GeoJSON objects.

Data format

GeoJSON is convenient for inspection and interchange, but repeating geometry and property names is expensive for a regular raster grid. A compact grid stores the spatial structure once and the values separately. The reader and writer share a format contract, trading general-purpose readability for smaller transfers and predictable decoding.

Evidence & results

The résumé records 592,800 cells per layer, a reduction from 349 MB of GeoJSON to an 8.2 MB binary representation, and a 1.2 MB initial load. It also records rendering more than 195,000 3D features in 12 ms. These are project benchmarks, not a guarantee for every device or network.

Interpretation

NDVI is a vegetation index, not a direct measurement of biodiversity or ecosystem health. A greener location is not automatically a healthier ecosystem. Comparing dates also requires attention to seasonality, missing data, and the source product. The map supports exploration; causal explanations require additional evidence.

What I would evaluate next

Benchmark the same regions and detail levels across devices, document the source product and observation windows directly in the interface, and test whether readers can distinguish vegetation intensity from change.
